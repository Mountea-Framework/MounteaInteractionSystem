Example Level Tour

M_Example.umap is a hub with one portal per feature. Walk into a portal to load its room, and use the "Back to hub" portal inside each room to return. Each room is a streamed sub-level, so leaving a room resets it: levers recharge, destroyed objects come back.

Room 1 · Interactor Types

Three booths with the same target. Only the interactor changes between them.

  • Booth A, Overlap: the target is detected only when the pawn's sphere overlaps it. Walking away clears focus.
  • Booth B, Trace Precise then Loose: Precise needs the crosshair on the target. Loose forgives a small miss. A thin obstruction in front of the target shows the difference.
  • Booth C, Mouse: top-down camera. Detection follows the cursor, not the pawn's facing.

Try it: stand in each booth and watch which target gets the attention widget.

Room 2 · Interactable Types

One booth per type. Each completion has a visible effect, so you can tell success from failure without the log.

  • Press: a door swings open as soon as you join.
  • Automatic: a light strip fades on after the interaction period, with no input.
  • Hold: a lever bar fills while you hold the key. Releasing early resets it.
  • Mash: a breaker needle climbs with each press. Pressing too slowly does nothing.
  • Hover: a terminal lights up while the cursor dwells on it (Mouse pawn only).

Room 3 · Standalone vs. Action Cycling

The NPC has three actions (Talk, Trade, Inspect) and cycles through them. The door next to it is standalone: no cycling, one immediate action.

  • Cycle the NPC's actions with the cycle input. The list wraps at both ends.
  • Starting an action locks the highlighted one until it ends.

Room 4 · Tag Whitelist and Blacklist

Two portals at the entrance spawn different pawns, so you can test both roles in one session.

  • Vendor (whitelist): only the player-tagged pawn can use it. The guard gets a rejection message.
  • Door (blacklist): the guard-tagged pawn is refused. The player pawn gets through.

Room 5 · Lifecycle and Cooldown

Three levers that differ only in their lifecycle settings.

  • Cycled: works forever, with a 5 s cooldown after each use.
  • Limited: works three times with a 2 s cooldown, then stops.
  • Once only: works once and never shows a cooldown.

Room 6 · Attention Range & Widget Modes

A cluster of interactables, more than the attention pool can hold. Walk through it and watch which ones get a widget.

  • Widgets switch from attention (far) to interaction (near) as you close in.
  • Widgets follow focus. Walking away releases them, with no leftovers.

Room 7 · EndPlay / Destruction Mid-Interaction

A long Hold lever and a pad a few metres away that destroys it. Start holding the lever, then have the pad used (it is a Press interactable).

  • The cancel event fires, and the interaction stops cleanly.
  • You can interact with something else straight away.
