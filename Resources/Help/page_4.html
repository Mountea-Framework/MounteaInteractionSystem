UMG Widget Setup

Two kinds of widget exist: the attention widget (pooled by the World Subsystem, shown above whichever actor is currently focused at a distance) and the interaction widget (shown once the player is in interaction range, carries progress/key-prompt/action-count). Both are plain UMG Widget Blueprints that implement the same interface — you can reuse one widget class for both, or use two.

1. Create the widget

Content Browser → Add → User Interface → Widget Blueprint. Fastest start: duplicate one of the shipped examples instead of starting blank.

Open Blank Template (WBP_InteractableWidget_Empty) Open Base Widget (WBP_InteractableBase) Open 10 Example Widgets

2. Implement the interface

In the widget's Class Settings, add Actor Interaction Widget under Implemented Interfaces. Every method below then appears under that interface in the Blueprint's function list — no C++ required (there is no C++ base class to inherit from; the interface is the whole contract).

Event / FunctionCalled when…
SetWidgetMode(NewMode)Widget should switch between None / Attention / Interaction display — drive your visibility/layout branch off this.
SetActionCount(TotalActions)Tier 2 action list size changed — e.g. show "1 of 3".
SetSelectedActionIndex(SelectedIndex)Player cycled to a different action.
UpdateWidget(InteractableInterface)General refresh hook — pull whatever you need straight off the interactable interface.
SetTitleText / GetTitleTextInteractable's display name.
SetBodyText / GetBodyTextDescriptive/flavour text.
SetKeyText / GetKeyTextThe "press [X]" prompt.
SetProgress / GetProgress0–1 progress — bind directly to a progress bar for Hold/Mash/Automatic/Hover types.
ToggleVisibility()Show/hide — this is the one native event (BlueprintNativeEvent); override it normally in the graph like any other event.
InteractionWidgetCommand(Command, Payload)Free-form escape hatch for anything project-specific.

Widget Mode reference

ModeMeaning
NoneNot currently relevant — hide everything.
AttentionFocused but out of interaction range — the pooled "something's over there" prompt.
InteractionIn range — full interaction widget: title, key prompt, progress, action count.

3. Assign the widget classes

Back in your config assets (page 1): set DefaultAttentionWidgetClass on the Interactor UI Config, and DefaultInteractionWidgetClass on the Interactable UI Config. That's it — no manual spawning anywhere:

  • The attention widget is spawned, pooled (AttentionWidgetPoolSize instances), and positioned by UMounteaInteractionWorldSubsystem automatically.
  • The interaction widget is hosted directly on the interactable component (it's a UWidgetComponent under the hood) and shown/hidden automatically based on distance and state.
