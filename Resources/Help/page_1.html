Config Assets Setup

Four small DataAssets drive every project-wide default — two for the Interactor side, two for the Interactable side, each split into a Runtime config (gameplay behaviour) and a UI config (widgets/visuals). None of this is required for the plugin to run — every field below also exists as a hardcoded fallback on the component itself — but without it you have no single place to tune defaults for the whole project.

1. Create the four DataAssets

In the Content Browser: Add → Miscellaneous → Data Asset, then pick the class from the list. Repeat four times. A suggested naming convention: 

DA_InteractorRuntimeConfig      (class: MounteaInteractorRuntimeConfig)
DA_InteractorUIConfig           (class: MounteaInteractorUIConfig)
DA_InteractableRuntimeConfig    (class: MounteaInteractableRuntimeConfig)
DA_InteractableUIConfig         (class: MounteaInteractableUIConfig)
There is no shipped default instance of any of these four classes — the plugin's old single-asset config (DA_DefaultInteactionConfig) is pre-v5.0 and orphaned; ignore it. Create your own four assets as above.

2. Assign them in Project Settings

Open Project Settings → Mountea Framework → Mountea Interaction System and drop each asset into its matching soft-reference slot.

Interactor UI Config

Drives the pooled attention widget — the "look, something is interactable over there" prompt shown on whichever actor is currently focused, before the player is close enough for the full interaction widget.

FieldTypeDefaultWhat it does
AttentionWidgetPoolSizeint325How many attention-widget actors the World Subsystem pre-spawns and recycles. No manual spawning needed — see page 4.
DefaultAttentionWidgetClassTSoftClassPtr<UUserWidget>(unset)Widget class used for the pooled attention prompt. Must implement Actor Interaction Widget.
AttentionWidgetFadeInTimefloat0.2sFade-in when a new actor becomes focused.
AttentionWidgetFadeOutTimefloat0.15sFade-out when focus moves away.
