Overview & Auto-Setup

Mountea Interaction System is a component-based interaction framework built on a two-tier focus model: your interactor picks one focused actor (Tier 1 — by weight, then distance), then cycles between that actor's individual interactable components (Tier 2 — Talk / Trade / Inspect, etc.). This guide walks through the six things every project needs, in the order you'll actually do them.

What the plugin sets up for you automatically

A few pieces of infrastructure are handled the moment the plugin loads — you do not need to configure these by hand in a normal project.

Collision Channels — Auto-created Gameplay Tags — Auto-registered Component Defaults — Safe fallback
Collision channels. Two custom channels — InteractionOverlap (Object channel, default response Ignore) and InteractionTrace (Trace channel, default response Block) — are written into your project's DefaultEngine.ini the first time the editor loads with this plugin enabled. Restart the editor once after the first load (or after using Setup Interaction Channels below) so the new channels fully apply.
Gameplay tags. A starter tag hierarchy (Mountea_Interaction.Interactor.Player, Mountea_Interaction.Interactable.NPC, etc.) ships in the plugin's own Config/Tags/MounteaInteractionSystemTags.ini and is picked up by UE's standard plugin gameplay-tag auto-scan — nothing to add to your project's own DefaultGameplayTags.ini unless you want project-specific tags alongside them. The plugin also checks GitHub for newer tag definitions on editor startup (toggle in Project Settings → Mountea Interaction System (Editor)).
Component defaults. Every interactor/interactable component has sensible hardcoded C++ defaults (ECC_Camera collision, sane periods and weights). The four config assets on the next page let you override these project-wide, but the plugin will not fail to initialise if you skip that page — it just falls back to those defaults per-component.

The six setup steps

Each step below is its own page in this tutorial — use the list on the left to jump around, or follow along in order.

#PageWhat you'll do
1Config AssetsCreate the 4 config DataAssets and assign them in Project Settings.
2Interactor SetupAdd an Overlap / Trace / Mouse interactor component to your Pawn and wire Enhanced Input.
3Interactable SetupAdd one of the 5 interactable components to whatever should be interacted with.
4UMG Widget SetupBuild a Widget Blueprint that implements Actor Interaction Widget and assign it.
5Testing & TroubleshootingPress Play and confirm it all works — plus fixes for the usual first-run snags.
