Before You Start

A quick checklist before you create your first interaction. Complete these steps once per project and you are good to go.

Collision Channels

Two channels — InteractionOverlap and InteractionTrace — are automatically registered when the plugin loads. No manual setup is required in most cases.

If the channels are missing after a fresh install, use Setup Interaction Channels from the Mountea Framework toolbar menu, then restart the editor.

Open Collision Settings

Interaction Defaults

Open the Mountea Interaction System settings and confirm the Default Interaction System Config asset is assigned. Without it the system cannot initialise properly.

Open Mountea Interaction Settings

Example Content

The plugin ships with example assets to help you get started. Browse them in the Content Browser to see a working interaction setup you can copy or learn from.
